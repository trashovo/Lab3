### Задание 1

#### Заполнение двумерных массивов

##### Текст задачи

Выполнить задание в виде конструкторов. Класс содержит единственное поле — двумерный массив.

1. Первый массив, размерностью $n \times m$, заполняется данными, вводимыми с клавиатуры, так что заполнение ведется по диагоналям параллельным побочной, начиная с правого нижнего угла.
2. Второй массив, размерностью $n \times n$, заполняется так: элементы, лежащие выше главной диагонали, являются случайными числами из интервала $[0;1]$ (больше $0.5$), а на главной диагонали и ниже — меньшие или равные $0.5$.
3. Третий массив, размерностью $n \times n$, заполняется для произвольного $n$ так же, как для $n=5$ по заданному образцу (заполнение по спирали/улитке).

##### Алгоритм решения

Создается класс `Matrix` с единственным закрытым полем `_data` (двумерный массив типа `double`).
Реализуются три целевых конструктора:

* Первый конструктор (ручной ввод) вычисляет максимальную сумму индексов `maxSum = (rows - 1) + (cols - 1)` и в цикле перебирает диагонали от `maxSum` до 0, считывая данные с клавиатуры через безопасный ввод.
* Второй конструктор перебирает элементы, и с помощью объекта `Random` генерирует числа: если столбец больше строки (выше диагонали), генерируется число из интервала $(0.5; 1.0]$, иначе — из $[0; 0.5]$.
* Третий конструктор для $n=5$ инициализирует массив жестко заданным образцом из методички, а для прочих $n$ реализует алгоритм обхода по спирали (4 цикла: вниз, вправо, вверх, влево) со сдвигом границ.
Для корректного отображения переопределяется метод `ToString()`.

### Задание 2

#### Работа с двумерными массивами

##### Текст задачи

Напишите программу, вычисляющую произведение тех столбцов двумерного массива (номера этих столбцов необходимо вывести), у которых первый элемент больше элементов расположенных на главной и побочной диагонали.

##### Алгоритм решения

В классе `Matrix` реализуется метод `Task2_MultiplyColumns()`. Сначала циклом перебираются элементы главной (`_data[i, i]`) и побочной (`_data[i, n - 1 - i]`) диагоналей для нахождения глобального максимума среди них.
Затем в цикле проверяется нулевая строка массива: если верхний элемент столбца строго больше найденного диагонального максимума, вычисляется произведение всех элементов этого столбца и выводится на экран вместе с его индексом.

### Задание 3

#### Работа с двумерными массивами как с матрицами

##### Текст задачи

Перегрузить необходимые операторы и посчитать значение матричного выражения. Перегрузить метод `ToString()` — сформировать строку из двумерного массива для отображения его на экране в виде таблицы. Приложить в отчет скрин-шот проверки на онлайн-калькуляторе, чтобы показать, что выражение посчитано верно.
Формула для варианта 15: $7 \cdot A - (B^T - 3 \cdot C)$.

##### Алгоритм решения

В классе `Matrix` через ключевое слово `operator` перегружаются бинарные операторы сложения `+`, вычитания `-`, а также умножения матрицы на скаляр `*` и умножения матрицы на матрицу. Реализуется метод `Transpose()` для получения транспонированной копии матрицы.
В главном меню инициализируются три матрицы $A, B$ и $C$, после чего требуемое по варианту выражение вычисляется в коде строго через применение перегруженных операторов: `7.0 * A - (B.Transpose() - 3.0 * C)`.

### Задание 4

#### Бинарные файлы

##### Текст задачи

Бинарные файлы содержат числовые данные. Исходный файл необходимо заполнить случайными данными, заполнение организовать отдельным методом.
Задача: Заполнить новый файл числами, которые являются произведениями соседних компонент исходного файла.

##### Алгоритм решения

В статическом классе `FileTasks` создается метод генерации бинарного файла, записывающий случайные целые числа с помощью `BinaryWriter`.
Создается метод обработки, который через `BinaryReader` считывает числа в список, проходит по нему циклом от первого до предпоследнего элемента, перемножает соседние значения ($a_i \cdot a_{i+1}$) и записывает полученные произведения в новый результирующий бинарный файл.

### Задание 5

#### Бинарные файлы и структуры (XML-сериализация)

##### Текст задачи

Бинарные файлы содержат величины типа `struct`, заполнение исходного файла необходимо организовать отдельным методом, обязательно использовать XML-сериализацию.
Файл содержит сведения об игрушках: название игрушки, ее стоимость в рублях и возрастные границы. Для детей какого возраста предназначается конструктор?

##### Алгоритм решения

Создается структура `Toy` с закрытыми полями названия, цены, минимального и максимального возраста, а также свойствами к ним. Структура помечается атрибутом `[Serializable]`.
Реализуются два метода: первый генерирует массив объектов `Toy` и сохраняет его в файл с помощью класса `XmlSerializer` (запись в поток `FileStream`). Второй метод десериализует XML-файл обратно в массив структур, проверяет наличие слова "Конструктор" в свойстве `Name` и выводит на экран найденные возрастные границы.

### Задание 6

#### Текстовые файлы (по одному числу в строке)

##### Текст задачи

В текстовом файле хранятся целые числа по одному в строке, исходный файл необходимо заполнить случайными данными, заполнение организовать отдельным методом.
Задача: Получить новый файл, увеличив каждый элемент исходного на 1.

##### Алгоритм решения

Реализуется метод, использующий `StreamWriter` для построчной записи случайных чисел в текстовый файл.
В основном методе обработки исходный текстовый файл считывается в массив строк (`File.ReadAllLines`). В цикле каждая строка конвертируется в числовой формат (`int.Parse`), увеличивается на единицу и построчно записывается в новый текстовый файл.

### Задание 7

#### Решить задачу с использованием структуры «текстовый файл»

##### Текст задачи

В текстовом файле хранятся целые числа по несколько в строке, исходный файл необходимо заполнить случайными данными, заполнение организовать отдельным методом.
Задача: Найти сумму первого и минимального элементов.

##### Алгоритм решения

Создается метод генерации файла, склеивающий несколько случайных чисел через пробел в строки.
В методе обработки файл читается построчно. Каждая строка разбивается на отдельные числа методом `Split` с флагом `StringSplitOptions.RemoveEmptyEntries`, что защищает программу от падения при лишних пробелах.
В ходе прохода по массиву первое обработанное число сохраняется в отдельную переменную, а минимальный элемент динамически обновляется. После прохода вычисляется их сумма.

### Задание 8

#### Текстовый файл (строки)

##### Текст задачи

В файле хранится произвольный текст. Переписать в другой файл строки, заканчивающиеся буквой 'б'.

##### Алгоритм решения

Создается вспомогательный метод для записи нескольких заранее подготовленных строк текста в файл.
Реализуется метод обработки, который считывает строки, удаляет лишние краевые пробелы методом `Trim()` и проверяет наличие буквы "б" (без учета регистра) на конце через метод `EndsWith("б")`. Если условие выполняется, строка переписывается в выходной текстовый файл.
